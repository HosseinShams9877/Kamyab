# واژه‌نامه‌ی دقیق پروژه

> مرجع: بخش الف-۲ سند. **این واژه‌ها در کل سامانه باید دقیقاً به همین معنی به کار بروند.** اگر جایی «پرونده» نوشته شده، جای دیگر «درخواست» یا «سفارش» نوشته نشود. این قاعده روی نام جدول‌های دیتابیس، متغیرها، متن رابط کاربری و مستندات — همه‌جا — اعمال می‌شود.

## جدول واژه‌ها

| واژه (فارسی) | معادل پیشنهادی کد | معنی دقیق |
|--------------|-------------------|-----------|
| مشتری | `Customer` | شخص حقیقی یا شرکتی که از موسسه خدمت می‌خرد. یک مشتری می‌تواند چند پرونده داشته باشد. |
| خدمت | `Service` | نوعی کار که موسسه انجام می‌دهد (ثبت شرکت، ثبت برند، کارت بازرگانی و...). خدمت یک «تعریف» است، نه یک کار انجام‌شده. |
| پرونده | `Case` | یک خدمتِ فروخته‌شده به یک مشتری. اگر آقای احمدی هم کارت بازرگانی بخرد هم ثبت برند، دو پرونده دارد. |
| دوره | `Period` | یک بازه‌ی اعتبار از یک پرونده. دوره‌ی اول یعنی ثبت، دوره‌های بعدی یعنی تمدید. پرونده‌ای که سه بار تمدید شده، چهار دوره دارد. |
| مسیر | `Path` | فهرست مرتب مراحلی که برای انجام یک کار باید طی شود. هر خدمت دو مسیر دارد: مسیر ثبت اولیه و مسیر تمدید. |
| مرحله | `Stage` | یک قدم از مسیر. فقط یک عنوان دارد، مثل «دریافت مدارک» یا «تاییدیه اتاق بازرگانی». |
| کار | `Task` | یک اقدام مشخص که به یک کارمند واگذار شده و سررسید دارد، مثل «تماس با مشتری برای تمدید». کار با مرحله فرق دارد: مرحله جزئی از مسیر خدمت است، کار یک وظیفه‌ی شخصی با تاریخ. |
| پیگیری | `FollowUp` | نتیجه‌ای که کارمند بعد از انجام یک کار ثبت می‌کند، مثل «مشتری پاسخ نداد» یا «موافق تمدید». |
| پرداخت | `Payment` | یک دریافت واقعی پول از مشتری، با تاریخ و مبلغ و روش. |
| بایگانی | `Archive` | کاری که تمام شده و بعد از مدتی از صفحه‌های روزمره کنار رفته. **حذف نیست.** |
| رهاشده | `Abandoned` | تمدیدی که خیلی از موعدش گذشته و عملاً انجام نخواهد شد. از فهرست کاری بیرون می‌رود ولی پاک نمی‌شود. |
| لغو | `Cancellation` | پرونده‌ای که وسط مسیر متوقف شده. همیشه با علت ثبت می‌شود. |

## تمایزهایی که نباید با هم قاطی شوند

- **مرحله (Stage) ≠ کار (Task):** مرحله بخشی از تعریف مسیر خدمت است و فقط عنوان دارد؛ کار یک وظیفه‌ی شخصی با مسئول و سررسید و اولویت است. مرحله خودش می‌تواند منجر به ساخت یک «کار» شود، ولی خودش «کار» نیست.
- **خدمت (Service) ≠ پرونده (Case):** خدمت یک «تعریف» است (الگو)؛ پرونده یک نمونه‌ی فروخته‌شده از آن خدمت به یک مشتری خاص است.
- **دوره (Period) ≠ پرونده (Case):** تمدید یک موجودیت جدا نیست؛ فقط یک دوره‌ی جدید از همان پرونده است.
- **بایگانی (Archive) ≠ حذف:** بایگانی فقط جابه‌جایی از صفحه‌های روزمره است؛ رکورد سر جایش می‌ماند و در جستجو و گزارش دیده می‌شود.
- **رهاشده (Abandoned) ≠ لغو (Cancellation):** رهاشده یعنی تمدیدی که از آستانه گذشته و عملاً نمی‌شود؛ لغو یعنی پرونده‌ای که با تصمیم و علت مشخص وسط مسیر متوقف شده.

## دستور اکید نام‌گذاری

هر موجودیت **یک نام واحد** دارد که در همه‌جای پروژه استفاده می‌شود. جدول ممنوعیت‌ها:

| نام درست | نام‌های ممنوع |
|----------|----------------|
| پرونده / Case | درخواست، سفارش، Order, Request |
| مرحله / Stage | Step (به‌عنوان موجودیت جدا)، وظیفه |
| کار / Task | Job، تسک بدون یکنواختی، Todo |
| دوره / Period | Cycle به‌عنوان موجودیت، اشتراک |
| پیگیری / FollowUp | Note (نوت با یادداشت مرحله فرق دارد)، تماس |
